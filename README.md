# Paws & Preferences

**Cute & Colorful** cat-swiping web app — vanilla HTML/CSS/JS.

## What you get
- `index.html` — main page
- `style.css` — cute pastel mobile-first styles
- `script.js` — swipe logic, localStorage resume, summary view
- `README.md` — this file

## How to run locally
1. Unzip the package.
2. Open `index.html` in your browser.
   - For best results use a local server (Live Server in VS Code) to avoid any image loading restrictions.
3. Swipe on mobile or drag with mouse on desktop.
4. Liked cats are shown on the summary screen.

## Notes
- Images are sourced from [Cataas](https://cataas.com/) (no API key required).
- LocalStorage keys:
  - `paws_cats`
  - `paws_liked`
  - `paws_index`
- Clearing progress is available in the summary screen.
